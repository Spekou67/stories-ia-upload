Privacy Policy - Stories.IA.Upload

Last updated: November 2026

1. Data Collection

Stories.IA.Upload operates exclusively on a private server for a single authorized TikTok account. The application only stores the OAuth access and refresh tokens required to authenticate API upload requests.

2. Data Sharing and Storage

No personal data, analytics, or user information is collected, sold, shared with third parties, or stored on external cloud servers. All authentication credentials remain strictly local to the owner's server.

3. Data Deletion

Revoking application access directly within TikTok account settings immediately invalidates all stored tokens.
